# Python Basics - 25BCON1638

## 📌 Project Title

**Python Basics Programs**

## 📝 Short Description

This repository contains basic Python programs created to practice and understand fundamental concepts of Python programming.

The programs cover basic topics such as factorial, Fibonacci series, lists, dictionaries, multiplication tables, and pattern printing.

## 📂 Programs Included

The following Python programs are included in this project:

1. **factorial.py** - Program to calculate the factorial of a number.
2. **fibonacci.py** - Program to generate the Fibonacci series.
3. **multiplication.py** - Program to print the multiplication table.
4. **pattern.py** - Program to print a star pattern.
5. **list.py** - Program demonstrating basic list operations in Python.
6. **dictionary.py** - Program demonstrating basic dictionary operations in Python.
